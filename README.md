Spot the Difference: two original hand-drawn scenes — Moonlit Garden (7 differences) and Lantern Market (8 subtler ones) — side by side in the browser. Click a difference in either picture to mark it on both, with a chime, a counter of how many remain, three hints, a timer, and a win screen per level. Pure static files, no network, sounds synthesized in WebAudio.

## Play it

```sh
node serve.ts
# open http://localhost:8080
```
